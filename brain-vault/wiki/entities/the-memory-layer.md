# The Memory Layer

**TL;DR:** This is a standalone training playlist, separate from the [[train-the-trainer-series]], that teaches people to build an AI "second brain." The brain is a folder of linked markdown with its own operating manual, skills, hybrid search, an MCP server and a heartbeat. Any harness can recall from it. This vault is the series' reference build, and its founding knowledge is the [[ai-training-guide]] and the Train-the-Trainer material ([[2026-10-21-ai-brain-series-standalone]]).

## Who / what
- **Format:** multi-part video playlist. Each part has a deck, narration and a hands-on lab, following the production pattern used for the [[train-the-trainer-series]].
- **Reference build:** this vault, plus the brain-tools package (CLI, search, MCP server, lint, heartbeat).
- **Tool-agnostic:** Obsidian is the recommended front end, but any editor or plain folder works.

## Role in this brain
The series teaches the [[llm-wiki-pattern]] and [[agent-memory-layers]]. It reuses earlier lessons: [[context-window]] and [[how-ai-finds-your-data]] (Session 4), [[agent-skills]] (Session 8), [[building-an-mcp-server]] (Deep Dive A), and [[containerization]] and [[secrets-management]] (Deep Dive B).

## Key facts
- Decided 2026-10-21: the series is its own playlist, and the training material and documentation are its founding knowledge ([[2026-10-21-ai-brain-series-standalone]]).
- Retrieval scope is the full stack: files plus index, BM25 and local embeddings (hybrid), an MCP server, and a scheduled heartbeat.
