# Decision: the series is named "The Memory Layer", with 90-minute parts

**TL;DR:** The standalone playlist is now called **The Memory Layer**. "AI Brain Series" was the working title. Each part's classroom version runs 90 minutes, the same length as the Train-the-Trainer sessions.

**Decided:** 2026-10-21  ·  **By:** Mark  ·  **Status:** active

## Decision
- Series name: The Memory Layer. Subtitle: "Build a Second Brain Any LLM Can Recall From."
- Classroom length: 90 minutes per part. The narrated video is shorter.
- Production pattern: a Kinvecta Blueprint deck, a facilitator guide, a lab and a narrated video for each part.

## Consequences / follow-ups
- The series folder and the [[the-memory-layer]] page were renamed. The old name is kept as an alias.
- Part 1, "Why your AI needs a brain", is the first part to build.
