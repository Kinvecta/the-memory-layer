# Lab 4 · Index, score, fix

The Memory Layer, Part 4: Recall at scale. 20 minutes, in a copy of `brain-vault/` with `brain-tools` installed.

| File | What it is |
|---|---|
| `lab-sheet.md` | The learner's steps A–E |
| `golden.csv` | The answer key: 6 questions, each with the page that should answer it |
| `run_eval.py` | Scores the answer key in keyword, semantic and hybrid modes: rank, recall@5, MRR |
| `extra-questions.csv` | 8 more questions for practice |
| `expected-results.md` | Facilitators: the expected output before and after the fix, and how to debrief |

Rule of thumb: **Words for exact. Meaning for ideas. Fuse the ranks. Measure every change.**
