# Lab 6 · Keep it alive and keep it safe

Time: about 20 minutes. Work on a **copy** of your vault (or of `brain-vault/`) that is a git repo.

| File | What it is |
|---|---|
| `lab-sheet.md` | The steps, A to E, with a box for each answer |
| `schedule-configs.md` | The heartbeat on macOS (launchd), Linux (cron) and Windows (Task Scheduler) |
| `lab6_check.py` | Plants two bad clippings in a temp copy, runs lint and the heartbeat, and prints what happened |
| `expected-output.txt` | A real run of `lab6_check.py` against `brain-vault/` |
| `planted-clip.md` | A clipping with a visible instruction aimed at your AI |
| `invisible-ink.md` | A clipping with an instruction hidden in Unicode tag characters |
| `make_invisible.py` | Writes any sentence in invisible ink, so you can test your own scanner |
| `answer-key.md` | Model answers and what to look for |

Needs `brain-tools` from this repository, version with Part 6 changes (`brain heartbeat --commit`).
