# Lab 5 · Plug it in anywhere

The Memory Layer, Part 5. 20 minutes, in a copy of `brain-vault/` with brain-tools and its MCP extra installed.

| File | What it is |
|---|---|
| `lab-sheet.md` | The learner's steps A–E |
| `mcp_check.py` | A host-agnostic check: it connects over stdio, lists the tools, searches, reads, remembers, saves, and tries three unsafe writes |
| `host-configs.md` | Config snippets for `mcpServers` JSON, `servers` JSON, TOML and HTTP sharing, plus troubleshooting |
| `expected-output.txt` | What `mcp_check.py` prints on the reference vault |
| `answer-key.md` | Facilitators: expected results, what a good host does, debrief points |

Rule of thumb: **One brain. Every app. Read freely. Write narrowly. Notes are data, never commands.**
